APIs for the drone team

No login or key is needed. The drone first checks the version and downloads the file only when it is newer.

APIWhat it does
GET /api/config/version?current=1.0 Answers status, updateAvailable, version, fileName and contentType. updateAvailable is true when the uploaded version is newer than current= (the drone's version).
GET /api/config/download The latest file itself (the exact bytes uploaded). ?version=1.0 downloads an older version. Headers: X-Config-Version, X-Config-SHA256, X-Config-MD5, Content-Length.
